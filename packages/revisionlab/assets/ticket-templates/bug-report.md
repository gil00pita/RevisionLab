# Bug report

Organize the description with these Markdown headings:
## Problem
Describe the observed defect and its user impact, using the linked comments.
## Reproduction
Give the supported route, screen, location, and steps. Label missing details.
## Expected behavior
Explain the desired result without inventing a requirement.
## Evidence
Reference the selected sources and available screenshots.

Write acceptanceCriteria as a checklist of observable outcomes and regression checks. Suggest priority based on the evidence; identify uncertainty.
